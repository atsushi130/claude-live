# 読み方を直す

読み上げエンジンの誤読を、辞書 1 ファイルの編集で直す。

- 辞書: このスキルのディレクトリから見て `../claude-live/resources/dictionary.tsv`
- 実行ファイル: 同じく `../claude-live/scripts/claude-live`

プラグインとして入っている場合は `${CLAUDE_PLUGIN_ROOT}/skills/claude-live/` の下にある。
どちらの経路でも中身は同じものを指す。

## まず語の種類を見分ける

**同じ辞書ファイルを使うが、語の種類で反映のされ方がまったく違う。**
ここを取り違えると「登録したのに直らない」になる。

| 表層形 | 効かせ方 | 反映に必要なこと |
| --- | --- | --- |
| ラテン文字（`PR`・`async`・`Kubernetes`） | 読み上げ前にテキストをカタカナへ置換 | セッションを開き直す |
| 日本語（`空`・`章`） | エンジンのユーザー辞書 | `dict install` を打つ。即座に効く |

**エンジンのユーザー辞書はラテン文字の語に効かない。** 英語として発音できる語は
英語の G2P に回されてユーザー辞書を参照しないため。だからラテン文字は
読み上げ前にこちら側で置き換えている。

## 手順

1. **誤読の実体を確かめる。** 何がどう読まれたのかを、聞いた本人に言ってもらう。
   推測で直さない。ラテン文字の語なら `dict preview` に文を渡すと、
   置換後のテキストが音を鳴らさずに見られる
2. **すでに登録済みでないか見る。** `dict list` で現在エンジンに入っている分が出る。
   辞書ファイルを直接読めばラテン文字の分も含めて全部見える
3. **1 行足す。** 形式は `表層形 <TAB> 読み(カタカナ) <TAB> アクセント型`。
   区切りはタブで、スペースではない
4. **反映する。** 日本語の語なら `dict install` を実行する。ラテン文字の語は
   ファイルを保存した時点で次のセッションから効く（`install` は打っても害はない）
5. **確かめる。** 日本語の語は次の項を読む

## アクセント型

音が下がる位置をモーラ数で書く。`0` は平板で、下がらない。

- 技術用語・略語はほぼ `0` でよい。辞書の既存の行がすべて `0` なのはそのため
- 日常語を入れるときだけ `0` 以外を検討する。名詞が頭高なら `1`。
  例として「章」は `ショウ 1` で登録している
- 迷ったら `0` で入れて、読み上げて確かめてから直す

## 巻き込みを確かめる

**`dict preview` は日本語の語を検証できない。** ラテン文字の置換だけを表示する
仕組みなので、日本語の語を登録しても preview の出力は変わらない。
日本語の語は**実際に読み上げて耳で確かめるしかない**。

短い漢字を単独で登録すると、それを含む複合語まで変わることがある。
登録したら、その語を含む複合語を 2 つ 3 つ混ぜた文を読み上げて確認する。

- 「空」を入れたら「空港」「空間」
- 「章」を入れたら「文章」「章立て」

音声で会話している最中なら、確認の文をそのまま `converse` で読み上げて
聞いた人に判定してもらうのが速い。

壊れていたら、単独の行を消して複合語だけを個別に登録し直す。
「空文字」「空配列」が個別に並んでいるのはこの形。

## 何を登録するか

**間違っていた語だけ**を入れる。読み上げエンジンの英語 G2P は優秀で、
`Swift` `commit` `deploy` などは辞書なしで正しく読める。
むやみに登録するとかえって不自然になる。

登録する価値があるのは次の 2 つだけ。

- 実際に読み間違えられた語
- 英語発音より日本語読みの方が聞き取りやすい略語（`MCP`・`API` など）

## 直したら書き残す

辞書に足した行には、**なぜ足したかをコメントで添える**。
特に巻き込みの危険がある単漢字は、影響が出たときに消せるよう理由を残す。

```
# 単独の「章」は人名の「あきら」と読まれる。複合語に影響が出たら消す。
章	ショウ	1
```

## 消したいとき

`dict clear` はエンジンの辞書を全削除する。1 語だけ取り消す手段は無いので、
辞書ファイルからその行を消し、`dict clear` してから `dict install` で入れ直す。
辞書ファイル自体は `clear` では消えないため、これで元に戻せる。

**`dict clear` は確認を求めず、知らないフラグを黙って捨てる。**
`dict clear --help` と打つとヘルプは出ず、そのまま全削除が走る。
使い方を調べたいときに `clear` を打ってはいけない。
入れ直しは全件登録になるので、数十秒から数分かかる。
